# 🏦 Sistema Bancário em C++ (Projeto POO)
![C++](https://img.shields.io/badge/c++-%2300599C.svg?style=flat&logo=c%2B%2B&logoColor=white)
Um sistema de gerenciamento bancário desenvolvido em C++, aplicando conceitos de Programação Orientada a Objetos (POO).
## ✨ Funcionalidades
- Cadastro, edição e remoção de clientes.
- Operações financeiras: Saque, Depósito, Saldo.
- Interface CLI organizada.
## 🛠️ Execução
1. g++ main.cpp -o banco. 2. ./banco.
